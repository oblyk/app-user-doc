# Ajouter un topo web à Oblyk

Voici les étapes à suivre pour ajouter un topo web à un site d'escalade.

**1. Rendez-vous sur la page de la falaise** sur laquelle vous voulez ajouter un topo web _(voir : [Trouver un site](../../sites-naturels/trouver-un-site))_.

**2. Rendez-vous sur l'onglet _[TOPOS]_**, faite **_[AJOUTER UN TOPO]_**, puis sélectionnez l'option : **_Topo Web_**

{: .images }
[![Ajouter un topo](../../../assets/images/ajouter-un-topo-partie-1.jpg)](../../../assets/images/ajouter-un-topo-partie-1.jpg)

**3. Complétez les infos et copiez le lien du site internet où l'on peut trouver le topo web de la falaise.**

{: .images }
[![Ajouter un topo](../../../assets/images/ajouter-topo-pdf-partie2.jpg)](../../../assets/images/ajouter-topo-pdf-partie2.jpg)

**4. Cliquez sur [CRÉER](){: .black-btn }**, voilà ! Vous avez ajouté un topo Web.
