# Les catégories

Les catégories vous permettent de différencier vos participants et d'obtenir autant de classements que vous avez de catégories.  
Si vous créez une catégorie Jeune et une catégorie Sénior, vous aurez un classement Jeune et un classement Sénior,  
avec à chaque fois la variante Homme et Femme qui sera faite automatiquement selon le genre du participant.

La catégorie est la porte d'entrée de votre contest, c'est pour cela qu'il faut au minimum en créer une.

Lorsque vous ajoutez une catégorie à votre contest, vous aurez un formulaire comme celui-ci :

{: .images }
[![Fenêtre nouvelle catégorie](../../../assets/images/contest-nouvelle-categorie-popup.png)](../../../assets/images/contest-nouvelle-categorie-popup.png)

Sur cette fenêtre, vous aurez les paramètres suivants :

**Le nom : (Obligatoire)**  
Le nom vous permet de nommer votre catégorie, par exemple : Jeune, Sénior, U15, Loisir, etc.  
Si vous n'avez qu'une catégorie, nous vous suggérons de l'appeler "Toutes catégories".

**Description :**  
La description vous permet d'ajouter un petit message qui sera affiché à vos participants lors de leur inscription,  
par exemple pour les orienter.

**Capacité maximale :**  
La capacité maximale vous permet de limiter le nombre de participants dans une catégorie.  
Cette limite concerne l'ensemble des participants. Si vous avez limité à 100, vous pourrez par exemple avoir un maximum de 80 hommes et 20 femmes.

_(Voir la section : [La capacité](b-la-capacite) pour plus d'informations sur la gestion de la capacité.)_

**Restriction :**  
Les restrictions vous permettent d'imposer des règles d'âge. Par exemple, pour votre catégorie "Jeune", vous pourriez vouloir la réserver aux moins de 17 ans.

Vous aurez le choix entre :
- Âge maximum / minimum personnalisé : vous permet de définir des classes d'âge non officielles.
- Les U6, U8, U10, etc. Selon les UXX que vous ajoutez à votre contest, le participant sera automatiquement inscrit dans l'une des catégories.

**Aucune distinction de genre dans cette catégorie :**  
Par défaut, vous aurez un classement "Homme" et un classement "Femme" pour chacune de vos catégories.
Vous pouvez cocher la case "Aucune distinction de genre" pour obtenir un classement mixte (hommes et femmes).

**Imposer la parité :**  
En cochant cette case, sur une catégorie de 100 places, vous aurez un maximum de 50 hommes ou 50 femmes.  
Vous devez définir une capacité paire pour activer cette fonctionnalité.

**Répartir cette catégorie en vagues :**  
Si vous cochez cette case, les participants de cette catégorie auront le choix entre plusieurs vagues.

**Auto-répartir les participants dans les vagues :**  
Si vous cochez cette case, vos participants n'auront pas le choix de leur vague et seront automatiquement inscrits dans celle ayant le moins
