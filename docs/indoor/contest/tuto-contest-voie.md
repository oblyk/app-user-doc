# Tuto - Contest de voie qualification + finale

Dans ce tuto, nous allons voir comment faire un contest de voie avec qualification et finale avec une catégorie Jeune et une catégorie Sénior.

## 1. Créez votre contest

Rendez-vous sur le dashboard de votre salle, cliquez sur [CONTEST](){: .black-btn } puis faites : [NOUVEAU CONTEST](){: .black-btn }  
Vous arriverez sur ce formulaire :

{: .images }
[![Nouveau contest](../../../assets/images/nouveau-contest_desktop.png)](../../../assets/images/nouveau-contest_desktop.png)

Renseignez à minima :
- **Un titre :** Exemple "Contest fin d'année".
- **Date de début et fin du contest :** La date du jour de votre contest.
- **Date de début et fin des inscriptions :** La période sur laquelle vous autorisez les inscriptions à votre contest.
- **Type de catégorisation :** choisissez "Catégorisation personnalisée (loisir, expert, etc.)"

Laissez le reste des informations par défaut.

## 2. Créez vos catégories

Pour ce tuto, nous allons créer 2 catégories :
- **Jeune** de 0 à 16 ans (inclus)
- **Sénior** 17 ans et +

Dans le bandeau **"Les catégories"** faites [+ AJOUTER](){: .light-btn }

Cette fenêtre s'ouvre :

{: .images }
[![Ajouter une catégorie](../../../assets/images/contest-ajout-categorie-jeune.png)](../../../assets/images/contest-ajout-categorie-jeune.png)

Renseignez **"Jeune"** dans le nom, dans **"type de restriction"** vous pouvez choisir **"Âge minimum / maximum personnalisé"** et renseignez 16 dans l'âge maximum.
Puis cliquez sur [CRÉER](){: .black-btn }

## 3. Créez une épreuve

Oblyk vous permet de créer des combinés, dans le cadre de ce tuto, nous allons juste faire un contest d'une épreuve de voie.

Dans le bandeau Épreuve, cliquez sur [+ AJOUTER](){: .light-btn }.

Dans la fenêtre qui s'ouvre :

{: .images }
[![Nouvelle épreuve](../../../assets/images/contest-ajouter-epreuve-voie.png)](../../../assets/images/contest-ajouter-epreuve-voie.png)

Choisissez **"Voie"** dans **"Type d'escalade de l'épreuve"**, et faites [CRÉER](){: .black-btn }

## 4. Créez votre étape de qualification

Notre épreuve de voie aura deux étapes, une étape de **"Qualification"** et une étape de **"Finale"**, commençons par les qualifications.

Dans le bandeau **"Voie : Les étapes"** faites [+ AJOUTER UNE ÉTAPE](){: .light-btn }.

Cette fenêtre s'ouvre :

{: .images }
[![Nouvelle étape](../../../assets/images/contest-ajouter-qualification-prise-la-plus-haute.png)](../../../assets/images/contest-ajouter-qualification-prise-la-plus-haute.png)

Pour le nom de l'étape, renseignez **"Qualification"** et choisissez **"Prise la plus haute atteinte"**.  

## 5. Ajouter les voies de qualification

Il est temps d'ajouter les voies de qualification, pour cela cliquez sur [+ AJOUTER DES VOIES](){: .light-btn } dans le bandeau **"Les voies de qualifications par catégories"**

Cette fenêtre s'ouvre :

{: .images }
[![Ajouter des voies](../../../assets/images/contest-ajouter-voies-qualification-jeune.png)](../../../assets/images/contest-ajouter-voies-qualification-jeune.png)

Pour ce tuto, nous allons imaginer qu'il y a 5 voies de qualification jeunes, et 5 voies de qualification seniors. Mais les hommes et les femmes font les mêmes voies.

Nous allons compléter le formulaire de la manière suivante :

- **Nombre de voies à faire :** 5
- **À qui sont destinées ces 5 voies :** Voies hommes et femmes
- **Ces 5 voies sont communes à quelles catégories :** Jeune
- Remplissez ensuite le début et fin de l'étape, exemple de 10h à 14h

Faites de même pour les voies de qualification seniors. La seule différence sera de choisir la catégorie Sénior.

Pour chaque voie, renseignez le nombre de prises de la voie.

{: .images }
[![Structure qualification](../../../assets/images/contest-structure-qualification-voie.png)](../../../assets/images/contest-structure-qualification-voie.png)

## 6. Ajouter les voies de finale

Maintenant que nous avons nos voies de qualification, nous allons créer notre finale.

Remontez dans la page jusqu'à trouver le bandeau "Voies : Les Étapes" et re-cliquez sur [+ AJOUTER UNE ÉTAPE](){: .light-btn }

Dans la fenêtre qui s'ouvre, donnez le nom **"Finale"** et choisissez **"Prise la plus haute atteinte"**.

Une fois votre étape créée, ajoutez les voies de finale. 
Pour ce tuto, imaginons qu'il y ait une voie jeune femme, une voie jeune homme, une voie senior femme et une voie senior homme.

Commencez par ajouter la voie jeune femme. Cliquez sur [+ AJOUTER DES VOIES](){: .light-btn } dans le bandeau "Les voies de finale par catégories".

Dans la fenêtre qui s'ouvre :

{: .images }
[![Ajouter voies final femme](../../../assets/images/contest-ajouter-final-voie-jeuen-femme.png)](../../../assets/images/contest-ajouter-final-voie-jeuen-femme.png)

Complétez le formulaire de la manière suivante :

- **Nombre de voies à faire :** 1
- **À qui est destinée cette voie :** Voies femmes
- **Cette voie est commune à quelle catégorie :** Jeune
- Remplissez ensuite le début et fin de l'étape, exemple de 19h à 20h

Faites de même pour les voies : jeune homme, senior femme et senior homme.

Pour chaque voie, renseignez le nombre de prises.

Vous devriez vous retrouver avec une étape de finale qui ressemble à ceci :

{: .images }
[![Structure finale](../../../assets/images/contest-structure-finale-voie.png)](../../../assets/images/contest-structure-finale-voie.png)

## 7. Conclusion

Nous avons fini de paramétrer notre contest !

Votre page devrait ressembler à ceci :

{: .images }
[![Contest overview](../../../assets/images/contest-structure-voie-overview.jpg)](../../../assets/images/contest-structure-voie-overview.jpg)

Si la structure vous semble correcte, vous pouvez **"Publier"** votre contest pour que les futurs participants puissent s'inscrire.
