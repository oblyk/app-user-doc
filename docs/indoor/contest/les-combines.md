# Les combinés

Les combinés vous permettent de faire plusieurs épreuves au sein du même contest. Celui ou celle qui se classe le mieux
dans les différentes épreuves remporte le classement général.

Les combinés sont constitués de 2 à X épreuves, même si habituellement un combiné est constitué de 3 épreuves : Voie + Bloc + Vitesse.
Rien ne vous limite à cela, vous pouvez construire un combiné de 5 épreuves de bloc pour faire, par exemple, des circuits par thématique.

Vous pouvez construire un combiné depuis n'importe quel contest. Une fois passées les étapes de configuration de vos catégories et de vos vagues _(si vous en avez)_, vous pourrez ajouter des épreuves à votre contest.

## Le classement d'un combiné

Le combiné a un classement par épreuve, par exemple, vous pouvez avoir un classement "Bloc", un classement "Voie" et un classement "Vitesse".

Dans chaque épreuve, vous pourrez définir une ou plusieurs étapes avec leurs propres systèmes de points et donc de classement.

Vous pouvez ainsi avoir un combiné tel que :
- Épreuve de Bloc
  - Étape de bloc : 1000 points divisés par le nombre d'ascensions + zone
- Épreuve de Voie
  - Étape de voie : Prise la plus haute atteinte
- Épreuve de Vitesse
  - Étape de vitesse : Meilleurs temps

Vos compétiteurs participent à chaque épreuve et étape, et se classent dans chacune d'elles.

Pour établir le classement général de vos différentes épreuves, il faut que vous choisissiez comment classer vos classements.

Vous aurez le choix entre quatre méthodes qui donnent différents résultats en fonction de ce que vous souhaitez. Rendez-vous dans la prochaine section [le classement des combinés](classement-des-combines).
